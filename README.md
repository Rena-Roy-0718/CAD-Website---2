# CAD Tool v2

A lightweight browser-based CAD (Computer-Aided Design) application built using HTML, CSS, and JavaScript. This project is the second increment of my journey to build a complete CAD system from scratch, adding new shapes, measurement tools, and editing capabilities with each version.

## Features

### Shapes

* Triangle
* Line
* Curve
* Rectangle
* Square
* Circle
* Ellipse
* Pentagon
* Hexagon
* Arrow
* Star

### Editing Tools

* Place shapes on the canvas
* Move shapes using drag and drop
* Select and modify existing shapes
* Change shape colors
* Filled and hollow modes
* Adjust scale and stroke width
* Delete selected shapes
* Clear the entire canvas

### Saving

* Save selected shapes
* Saved shapes panel for quick access
* Select previously saved shapes from the sidebar

### Measurements

* Pixels (px)
* Millimetres (mm)
* Centimetres (cm)
* Inches (in)
* Feet (ft)
* Metres (m)

### User Experience

* Ghost preview before placement
* Interactive toolbar
* Shape thumbnails
* Dynamic rulers
* Modern CAD-inspired interface

## Getting Started

No installation is required.

Open the following file in any modern web browser:

```text
CAD Website 2.html
```

Or simply drag and drop the file into Chrome, Firefox, Edge, or Safari.
